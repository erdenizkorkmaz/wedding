# Wedding Website

A beautiful and modern wedding website built with Next.js, featuring:

- Multi-language support (English, Korean, Turkish)
- Responsive design with Tailwind CSS
- Smooth animations with Framer Motion
- Browser language detection

## Features

- Language switcher
- Wedding information display
- Responsive layout for all devices
- Beautiful animations and transitions

## Technology Stack

- **Next.js** - React framework with App Router
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library for React
- **next-intl** - Internationalization for Next.js

## Getting Started

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) to see the website

## Customization

- Update translations in `src/i18n/locales/` directory
- Modify the wedding details in the page component
- Customize colors in the Tailwind configuration

## Deployment

The site is ready to be deployed on platforms like Vercel or Netlify.

```bash
npm run build
```
